# Atividade com Kubernetes

## Instrucoes

O proposito desse trabalho e colocar a aplicacao em python que se encontra no nosso repositorio para rodar dentro de um cluster Kubernetes.

Link:
https://github.com/profdiegocbcastro/gerencia-de-config/tree/main/APIs%20para%20exerc%C3%ADcios/api-python

O cluster deve ter:
- Deployment com pelo menos 2 pods
- Service
- Ingress

Caminho: `gerencia-de-config/APIs para exercícios/api-python`

Feito: API Python no Kubernetes com Deployment (2 pods), Service e Ingress.
